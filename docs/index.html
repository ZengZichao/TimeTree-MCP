Overview

TimeTree MCP bridges the TimeTree evolutionary biology database and MCP-compatible AI clients. It allows language models to search and resolve taxon names, query divergence times between species, build evolutionary timelines, and access database metadata — all through natural language interaction.

This enables questions like:

  • "When did humans and mice share a common ancestor?" → ~84 million years ago
  • "How long ago did cats and dogs diverge?" → ~53 million years ago
  • "What is the evolutionary timeline of primates?"

What is TimeTree?

TimeTree is a scientific database maintained by Temple University that contains divergence time estimates between species, compiled from thousands of published molecular evolution studies. It is a free public resource for research and educational use.

What is MCP?

The Model Context Protocol is an open standard that enables AI assistants to securely connect to external data sources and tools. This server implements the MCP specification over stdio transport, making it compatible with Claude Desktop, MCP Inspector, and any MCP-compatible client.

Features

  • 4 MCP tools covering core TimeTree search capabilities
  • Pairwise divergence time queries with full study-level data
  • Single-taxon timeline queries with biodiversity metrics
  • Taxon name resolution with disambiguation support
  • Stdio transport — compatible with Claude Desktop & MCP Inspector
  • Zero API keys required — TimeTree is a free public resource
  • Configurable via environment variables
  • TypeScript with full type definitions and source maps
  • Minimal dependencies — only MCP SDK and Zod

Available Tools

The server exposes four MCP tools that map directly to TimeTree's search capabilities:

search_taxa
Search the TimeTree database for a taxon name and return all matching taxa with NCBI taxonomy IDs.
Parameters: taxon (string, required)
get_divergence_time
Get the estimated divergence time between two taxa, including all supporting studies with PubMed links.
Parameters: taxon_a, taxon_b (string, required)
get_timeline
Build an evolutionary timeline for a single taxon with node-level biodiversity metrics.
Parameters: taxon (string, required)
get_timetree_info
Get general information and current statistics about the TimeTree database. No parameters required.
Parameters: none

Architecture

The server is organized into three layers, each with a clear separation of concerns:

⇄
MCP Server

→
TimeTree API

1

types.ts — Type Definitions

Defines TypeScript interfaces for all structured data extracted from TimeTree responses, including taxa, divergence times, study estimates, and timeline nodes.

2

timetree-client.ts — HTTP Client & Parser

Wraps TimeTree's AJAX endpoints. Since TimeTree does not expose a JSON API, the client sends POST requests and parses returned HTML fragments using regular expressions to extract structured data.

3

server.ts — MCP Server

Registers four MCP tools and wires them to the client. Uses the low-level Server class from @modelcontextprotocol/sdk with stdio transport for communication with MCP clients.

How It Works

TimeTree's website provides a search interface backed by internal AJAX endpoints that return HTML fragments rather than JSON. This MCP server wraps those endpoints:

  1. Name resolution — POSTs to /ajax/name/timeline/{taxon} and parses the HTML <select><option> elements to extract taxon matches with NCBI IDs.
  2. Divergence time — POSTs to /ajax/pairwise/{idA}/{idB} and parses the SVG response, extracting <circle> elements for study estimates and <text> elements for summary statistics.
  3. Timeline — POSTs to /ajax/timeline/{id} and parses the SVG tree structure for node metadata including divergence time, clade size, phylogenetic diversity, and evolutionary distinctiveness.

Installation & Usage

Prerequisites

  • Node.js ≥ 18.0.0 (requires built-in fetch API)
  • npm or a compatible package manager

From Source

git clone https://github.com/ZengZichao/TimeTree-MCP.git
cd Timetree-MCP
npm install
npm run build

The compiled server will be available at dist/index.js.

Configure with Claude Desktop

Add the server to your Claude Desktop configuration file:

{
  "mcpServers": {
    "timetree": {
      "command": "node",
      "args": ["/absolute/path/to/Timetree-MCP/dist/index.js"]
    }
  }
}

Restart Claude Desktop, and you can now ask questions like:

  • "When did humans and chimpanzees diverge?"
  • "What is the divergence time between cats and dogs?"
  • "Search for the taxon 'primates' in TimeTree"

Configuration

The server can be configured via environment variables. All values are optional:

Variable Default Description
TIMETREE_BASE_URL https://timetree.org Base URL of the TimeTree web service
TIMETREE_TIMEOUT 30000 HTTP request timeout in milliseconds
TIMETREE_USER_AGENT timetree-mcp/0.1.0 User-Agent header sent with requests
